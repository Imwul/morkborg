# Local webfonts

The Reference Desk uses **Barlow Condensed Black (900)** for Latin headings and the wordmark. **Pretendard Variable** supplies Korean headings, controls and body text. Headings and table values use heavier weights; descriptions and provenance remain quieter. The former Alegreya prose and Grenze Gotisch display stacks are no longer selected.

All font files are served locally with their existing SIL Open Font License files. No font dependency or external runtime request was added. Alegreya and Grenze Gotisch files are retained for compatibility with old exports.

- BarlowCondensed-Black.ttf / BarlowCondensed-OFL.txt
- PretendardVariable.woff2 / Pretendard-OFL.txt
