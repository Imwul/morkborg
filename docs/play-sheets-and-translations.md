# 통합 시트, 직업 생성, 한국어 병기

2026-09-03. 첨부한 던전·몬스터 예시와 캐릭터 시트를 기준으로 읽기 화면을 재구성했다. 이미지 생성은 사용하지 않았다.

## 화면

- Dungeon 후보와 저장한 Dungeon이 동일한 `DungeonSheet`를 사용한다. 개요 11항목과 각 Room 6항목을 한 프레임 안에 표시하고, 3440px에서는 개요와 방을 각각 4열로 배치한다.
- Monster는 이름·외형·욕망을 큰 글자로, HP·사기·방어구·공격·특수능력을 아래 구획에 표시한다. 빈 선택 항목은 ‘추가 항목 직접 입력’으로 펼친다.
- Character는 이름/직업/배경, 노란 HP·능력치 기둥, 무기/방어구/장비/은화를 나눈 시트다. 실제 선택된 직업 능력과 제한을 함께 읽는다.
- 본문을 누르면 기존 편집기를 열며 출처도 함께 나타난다. 단일 재굴림·직접 입력·저장된 ID는 유지한다. 제목 Grenze Gotisch, 영문 본문 Alegreya, 한국어 Pretendard와 충분한 행간을 사용한다. 강조색은 `#ffe900`이다.
- 작은 화면에서는 구획이 세로로 이어진다. 내용을 자르거나 강제로 축소하지 않으므로 긴 직업 능력·많은 방·직접 작성한 장문은 세로 스크롤이 필요하다.

## 캐릭터 규칙과 저장

Classless / Class를 고른 뒤 생성한다. Class는 무작위 또는 직접 선택하며, 기본 룰북 6개·FERETORY 4개·HERETIC 2개를 지원한다. 개인 자료의 `library.notes.characterClasses`에 검증된 클래스 정의와 종속 장비 표가 있다. 원문 선택지의 가중치, 독립 굴림, 직업별 HP·은화·징조·능력 보정·무기·방어구·두루마리 제한을 적용한다.

기본 장비와 Terrible Traits/Broken Bodies에 Bad Habits/Troubling Tales를 추가했다. 배경·능력에 따라 주어지는 무기, 동료, 장비도 따로 생성한다. 종속 항목의 `slot: feature:<owner-id>`는 해당 원문 항목 재굴림/삭제에만 반응하며, 복제할 때 참조까지 새 UUID로 바뀐다. 사용자 추가 장비는 유지한다.

`Character`에 선택 필드 `classId`, `background[]`, `classFeatures[]`, `powerUses`와 항목의 `entryRoll`을 추가했다. 기존 schemaVersion4 저장과 하위 호환되므로 기존 데이터를 재생성하거나 이관하지 않는다. 기존 캐릭터의 빈 장비를 강제로 채우지 않는다. 전체 재굴림을 선택할 때 새 완성형 생성 절차를 적용한다. Classless로 전체 재굴림하면 이전 classId와 능력이 제거되고 메모·생존 상태는 보존된다.

원문에서 ‘고르기’만 지시한 일부 목록은 앱이 균등 선택한다. Pale One의 +1/+1/−2 문구는 최종 능력 보정에 적용하며 원문 표현의 해석을 출처 설명에 명시했다. 능력을 실제 사용할 때 발생하는 피해·소모·변신은 생성 시 미리 적용하지 않는다. Heretical Priest의 중갑 권능 예외와 Fanged Deserter의 Bite DR10도 반영했다.

## 번역과 Oracle

개인 자료의 11,796개 표 항목(중첩 후속 항목 포함)에 한국어 metadata가 있다. 합성 문구와 효과를 위한 사전은 8,188개 고유 문구다. 원문 영어·표 가중치·주사위 수치는 수정하지 않는다. 표별 번역을 우선하고, 생성한 합성 문구는 가장 긴 원문 구절부터 조합한다. 식량·탄약·탕약 등 굴린 수량은 별도 문형을 사용한다. 고유명사는 원래 철자를 보존하며 주사위만 있는 값은 중복 번역을 표시하지 않는다. 사용자가 자유롭게 작성한 임의의 영어를 온라인 번역하는 기능은 없다.

자료는 IndexedDB의 기존 개인 자료 묶음에 포함된다. 캠페인 localStorage에 사전을 복사하지 않는다. 배포 서버와 Git에는 책 추출 데이터·번역 사전을 올리지 않는다. 새 브라우저는 갱신한 `morkborg-private-data.json`을 가져와야 한다. `scripts/enrich-private-data.py`가 개인 번역 맵을 검사한 뒤 library/oracles와 개인 묶음을 함께 갱신한다.

Oracle 목록에는 Action과 Descriptor를 각각 하나씩 표시하고 각 원문 1번·2번 표에서 한 번씩 굴린다. 나머지 표는 한 번만 굴린다. 중복 굴림 조합 선택 UI는 제거했고, Mythic Random Event용 내부 다단계 절차와 원문 표는 유지한다. 결과와 원문 목록에 영문 아래 한국어를 표시한다. 분류 UI는 출처 PDF만 남겼으며 태그·범주 필터와 검색을 제거했다. 저장 형식 호환을 위해 내부 원본 metadata는 유지한다.

- 실제 UI: 별도 SHEET QA 캠페인에서 Classless → 무작위 Dead God’s Prophet → Shedding Vicar를 생성했다. 방어구 없음·시작 두루마리, 직접 이름 수정·HP0·한국어 메모 저장, 페이지 재접속 후 복원, Classless 전환 시 직업 능력 제거를 확인했다.

## 2026-09-03 — 목록 간소화·자동 갱신·Eat Prey Kill

Oracle 목록은 제목, 주사위, 즐겨찾기만 보이고 카드 전체를 눌러 선택합니다. 책 이름·PDF 페이지·항목 수·조건은 선택한 표의 `출처 · 표 정보`에 모았습니다. Mythic 사건 단서의 출처도 접었으며, 캠페인·던전·캐릭터·몬스터 목록의 최소 높이와 여백을 줄였습니다. 던전 목록의 지역·방 수·수정 시간은 유지했습니다. 생성 결과의 영문 및 작은 한국어 표시는 그대로 유지합니다.

FERETORY의 Eat Prey Kill을 PDF14–23에서 대조했습니다. 54개 원문 결과와 변형·누락 조건을 개인 자료에 보존했으며, 실제 숫자 HP가 있는 51개는 원문 개체 선택에서 사용할 수 있습니다. 현재 7지역의 기본 생성 풀은41개입니다. 기본 생성 방식은 `Eat Prey Kill · 지역 생물`, 기존 `The Monster Approaches`는 선택 가능한 별도 방식으로 유지합니다. Galgenbeck은 Tveland, Grift는 EPK 자체 지역 목록을 참조합니다. 원문 d6 사냥 판정을 그대로 구현했다고 표시하지 않습니다. Grift의 Lentil Lice에 딸린 수치는 농민의 것이므로 벌레에게 부여하지 않습니다. Cursed Trout와 변형 미선택 Carcasswan도 자동 전투 프리셋에서 제외합니다.

Sölitary Depths PDF26–33의 지역별 몬스터 참조를 원문 표기와 PDF 페이지를 구분해 보존했습니다. 일치하는 EPK 개체에는 해당 참조를 출처에 연결했습니다. 원문에서 책/페이지가 불명확한 참조를 억지로 다른 개체에 연결하지 않았습니다. 생물의 원문 설명을 공격 설명에 중복 복사하던 부분도 수정했습니다.
