# 홈과 한국어 병기 수정

기준 커밋: `f2c514454dad013ea4f131c849b2cd111a1e2809`.

## 확인한 문제와 수정

공용 `Field`가 번역을 `editing` 상태에서만 표시했다. 한국어를 읽기 위해 편집을 열어야 했고, 세 줄짜리 입력칸이 원문과 번역 사이의 불필요한 여백을 만들었다. 번역을 원문과 같은 읽기 영역에 붙이고, 보기 상태에서 바로 표시한다. 한국어는 14px, 원문보다 가벼운 굵기로 유지한다. 던전의 항목 간 여백도 소폭 줄였다.

방의 한국어는 별도 ‘한국어 도움말’에 모아두지 않고 각 구성 요소 바로 아래에 병기한다. 긴 방 미리보기는 원문 세 줄·번역 두 줄까지 표시하며, 방을 펼치면 전체를 읽을 수 있다. 짧은 번역을 위한 별도 클릭은 없다. 수동 수정한 필드에는 이전 원문의 번역을 붙이지 않는다.

| 확인 항목 | 이전 | 이후 |
| --- | --- | --- |
| QA 던전의 번역이 있는 9개 필드 | 보기 상태에서 0개 표시 | 9개 모두 즉시 표시 |
| 짧은 필드 번역 읽기 | 편집 진입 1회 | 0회 |
| 펼친 방의 번역 읽기 | 한국어 도움말 1회 | 구성 요소 바로 아래, 0회 |
| 검색 → 직접 굴림 | 결과에서 1회 | 홈에서도 동일하게 1회 |
| 홈 → 보관함 | 홈 없음 | 현재 캠페인이 있으면 1회 |
| 캠페인을 선택하지 않은 상태 → 보관함 | 캠페인과 메뉴를 찾아 이동 | 목적지를 기억하고 캠페인 선택 후 바로 이동 |
| 다른 화면 → 홈 | 없음 | 상단 홈 1회 |

## 홈

첫 화면은 검색 중심의 전체 목차다. 기존 작업대도 별도로 그대로 열 수 있다. 홈에는 레퍼런스 작업대, Oracle 라이브러리, 자료 및 규칙, City Crawl, Mythic Fate, 재앙·여행, 플레이 화면, 던전·캐릭터·몬스터·NPC·조우 보관함, 보관한 자료, 캠페인 선택을 연결했다. 세션·연대기·실마리·소문·유물·짧은 기록·캠페인 노트는 접힌 보조 기록에 있다. 가져오기와 소개·출처도 접근 가능하다.

검색에는 캠페인이 필요 없다. 캠페인 전용 항목을 먼저 눌렀다면 기존 캠페인을 선택하거나 새로 만든 후 원래 고른 보관함으로 이어진다. 단순히 홈을 여는 동작은 캠페인 선택, 던전/방 선택, 저장 내용을 초기화하지 않는다.

고정/최근은 내용이 있을 때만 작은 바로가기로 표시한다. 활성 Pack의 이름과 해제 동작은 유지하며, 없는 Pack의 자리나 비어 있는 도구 패널은 만들지 않는다. PLAY는 기존 접힌 편의 도구 입구로 남는다.

## 브라우저 검증

`acceptance.mjs`를 격리된 QA 저장소에서 360 / 768 / 1440 / 3440px로 실행했다.

- 검색 → Reaction 직접 굴림 → 복사 → 출처 → 닫기 후 홈 복귀.
- 독립적인 참조 화면 네 곳과 Mythic, 캠페인의 기존 섹션 15곳을 홈에서 실제로 열기.
- 던전 보기 상태의 9개 번역, 방 미리보기와 펼친 구성 요소의 병기 확인.
- 홈으로 복귀 및 새로고침 전후 저장소 전체 일치 확인. 섹션 이동에서는 기존 navigation workspace만 달라지고 캠페인 내용은 일치.
- 격리된 던전 입구를 명시적으로 수정한 뒤, 이전 번역이 사라지고 수정값이 새로고침 후 보존됨을 확인.
- 새 프로필에서 캐릭터를 먼저 누르고 캠페인을 새로 만든 뒤 캐릭터 보관함으로 연결되는 경로 확인.

`state-checks.mjs`는 기존 편의 설정을 가진 360 / 768 / 1440px에서 Pack 표시·해제·저장, Pin 재접속·직접 굴림, 활성 캠페인이 없을 때 기존 캠페인 선택 후 목적지 복귀를 확인한다. 이 참조/편의 동작들은 캠페인 저장을 변경하지 않는다.

스크린샷을 직접 검토했다. 768px에서 목차가 좁은 세 열로 나뉘어 한국어 단어가 꺾이는 문제를 발견하고, 두 열 + 아래쪽 보관함 배치로 수정했다. 3440px에서는 기존 제한된 콘텐츠 폭을 유지한다. 가로 넘침과 JS 오류가 없었다. 밝은/어두운 OS 설정에서도 기존 종이/잉크 색상을 유지하며, 확인한 한국어 대비는 5.90:1이다. 홈의 클릭 영역은 최소 44px 높이를 유지한다.

개인 자료가 포함된 전후 이미지와 실행 결과는 Git에서 제외되는 `outputs/home-bilingual/`에 보관한다. 최종 공개 사이트 확인은 실제 배포 이후 별도로 수행한다.

## 범위와 검증

새 규칙·생성기·소스 콘텐츠·캠페인 스키마·저장 형식은 추가하지 않았다. 변경은 홈 연결, 번역 가시성, 인접 배치와 그 검증으로 제한했다. 사용하지 않게 된 방 번역 disclosure 스타일을 제거했다.

신규 회귀 테스트 6개를 추가했다. 기존 방 미리보기 테스트 두 개는 원문을 감싸는 span 구조만 반영했으며, 원문 보존·정확한 방 식별·중복 방지·저장 내용 불변 검증은 유지했다. 전체 694개 테스트 통과, lint/build 및 공개 빌드의 개인정보/비공개 자료 검사 통과.

번역이 없는 원문이나 사용자가 새로 쓴 내용에 번역을 만들어 붙이지 않는다. 긴 미리보기의 전체 내용, 편집, 출처는 의도적인 열기 동작으로 접근한다. 기존 Vercel 사이트에 반영하며, 정확한 커밋과 확인된 배포 상태는 최종 응답에 별도로 기록한다.
