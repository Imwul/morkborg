# 노트를 중심에 둔 플레이 도구

2026-09-23. 기준 커밋: `23bf9c7e174e354d567413c8e3e423174cbfe5fc`.

기록의 주인은 사용자의 노트다. 이 변경은 네 종류의 생성 자료를 다시 펼치고, 행동을 판정하고, 다음 참조를 찾는 데 범위를 둔다. 캠페인·일지·시간선·자동 자원 관리·장면 저장 기능을 추가하지 않았다.

## 보관함

생성 결과에만 **보관**이 나타난다. 다음 네 참조를 통해 만든 결과만 명시적으로 저장한다.

| 종류 | 기존 참조 |
|---|---|
| 캐릭터 | `procedure:character.core-classless` — Core / private SCVMBIRTHER 결과 |
| NPC | `procedure:workbench.npc` |
| 던전 | `procedure:sd.dungeon-preparation` — Core / private DNGNGEN 준비 자료 |
| 도시 | `procedure:aitc.settlement` |

다시 읽기, 이름·내용 수정, 복제, 복사, 삭제 취소, 내보내기·가져오기를 제공한다. 실제 생성 이름을 기본 보관 이름으로 사용한다. 화면에 있던 한국어 번역도 해당 결과 바로 아래에 보관한다. 수정한 내용과 생성 원본·출처를 구분하고, 이미 펼쳐서 굴린 조건부 하위 결과도 기존 복사 직렬화 경로로 포함한다. 몬스터·개별 오라클·행동 판정·장면은 이 보관함에 저장하지 않는다.

`morkborg-object-shelf:v1`은 이 브라우저의 로컬 자료다. 재개는 저장한 자료를 다시 펼치는 뜻이며, 탐색 진행이나 HP·식량을 자동으로 복원하거나 바꾸는 기능은 아니다. 다른 기기로 옮길 때는 내보낸 파일을 가져온다. 기존 v1–v6 캠페인 데이터와 마이그레이션에는 손대지 않았다.

## 행동과 짧은 절차

지도 오른쪽(좁은 화면에서는 아래)에 자유롭게 선택하는 행동을 둔다. 물건 근처에서는 물건 찾기, 사당에서는 기도를 먼저 보여주는 정도의 정렬만 한다. 다른 행동은 항상 이용할 수 있고 순서나 진행 잠금이 없다.

- 던전: 다음 방, 물건 찾기, 숨 돌리기/야영, 전투 이탈.
- 도시: 목표 탐색, 길 묻기, 기도, 숨긴 물건 회수.
- 8개 원문 절차를 **언제 → 판정 방법 → Strong/Weak/Miss → 후속 처리**로 요약한다. 해당 조건부 오라클에서도 부모 행동의 요약과 링크를 제공한다.
- 던전 판정 도구를 안내 바로 아래로 옮겼다. 전체 규칙과 구성 표는 펼쳐 읽을 수 있다. 부모 규칙의 구성 표 주사위를 행동 자체의 주사위처럼 크게 표시하지 않는다.
- Strong은 준비한 특별한 방, Weak는 일반 방, Miss는 위험을 해결한 뒤 방으로 연결한다. SD의 일반 방 Weak에 추가 대가를 자동 적용하지 않는다.
- SD Searching의 기존 엔진과 d4 발견 결과를 사용한다. 불명확한 Weak 결과의 보조 도구로 기존 Sölitary Depths Weak Hit 결과표를 열 수 있다.
- City Crawl의 Weak는 거리 참조, Fail은 상황을 해결한 뒤 거리 참조로 연결한다. 목표 도달과 새 거리 생성을 혼동하지 않는다.
- TR에 의존하는 Depths 행동은 이번 행동 메뉴에 노출하지 않는다.

`playGuidance.ts`는 앱이 작성한 요약과 화면 탐색 제안이다. canonical registry의 관계/행/표를 수정하지 않는다. `usePlayToolState`는 다른 참조를 보고 돌아왔을 때 현재 입력·결과만 유지하는 문서 내 메모리이며 저장 이력으로 직렬화하지 않는다. 기존 Search, Recent, Pins, Workbench와 같은 reader를 연다. 열기와 굴리기는 분리되어 있다.

## Mythic 목록

오른쪽 아래 **Mythic · CF**에서 Yes/No, 장면 판정, **인물·스레드**를 연다. 1,100px 이상에서는 바깥 화면을 계속 사용할 수 있는 비모달 패널이고, 좁은 화면에서는 닫기/뒤로가기 가능한 대화상자다.

- Characters / Threads를 나란한 25칸씩 제공한다. 목록 두 개만 `morkborg-mythic-lists:v1`에 저장한다.
- GME2 PDF 45–47(인쇄 44–46)의 목록 선택: 마지막으로 채운 5칸 구역까지 사용. 1구역이면 행 d10만, 2/3/4/5구역이면 구역 d4/d6/d8/d10 후 행 d10. 두 면이 한 구역/행을 가리킨다.
- 빈 칸은 CHOOSE. 자동으로 건너뛰거나 압축하지 않는다. 목록 전체가 비었으면 Current Context를 안내한다.
- PDF 112–114(인쇄 111–113): 같은 항목 최대 3칸. 별도의 명시적 정리 동작만 3칸→2칸, 그 밖의 중복→1칸으로 줄인다.
- 실물 주사위 입력을 지원하고 결과가 보이도록 스크롤한다.
- Event Focus 21–50은 Characters, 51–70은 Threads 선택 버튼을 제공한다. New NPC, PC 및 Current Context에는 기존 목록 선택을 강요하지 않는다. 장면 사건에서 목록 대상을 고를 때도 별도 클릭으로만 굴린다.
- 일반 Reference reader의 Lists 규칙과 Event Focus 결과에서도 같은 도구를 열 수 있다.
