## 남아 있는 한계

- 긴 표는 현재 페이지에서 여전히 세로 스크롤이 필요하다. 좁은 Workbench는 자체 스크롤과 다음 페이지로 이동하는 스크롤이 함께 존재한다.
- 넓은 화면에서 Workbench가 비어 있으면 양옆 여백을 유지한다. 문장을 화면 끝까지 늘리지 않기 위한 선택이다.
- 기존 선택적 기록 화면은 Reference Desk보다 메뉴와 설명이 많다. 이번 작업에서는 글자·정렬을 통일했으며 기록 기능 구조를 다시 작성하지 않았다.
- 보조 자료로 이동할 때 기존 Reference overlay/history가 남아 한 번 닫고 다시 진입해야 하는 경우를 관찰했다. 이번 시각 pass의 변경으로 수정됐다고 주장하지 않는다.
- `Alchemy` 검색은 현재 registry에서0건이었다. 원문 OCR의 이상한 띄어쓰기 등 기존 source/content 문제도 임의로 고치지 않았다.
- 이 결과는 CSS viewport3440px 기준이다. 실제 모니터의 물리적 크기, 운영체제 배율, 사용자의 시력에 대한 장시간 피로 평가는 대신할 수 없다.
