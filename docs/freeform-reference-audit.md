# Freeform Reference Desk — 구조 변경 및 검증 보고

검증일: 2026-09-12. 로컬 개발 화면에 적용했으며 원격 배포는 수행하지 않았습니다.

앱은 필요한 표와 공식을 찾아 열고 굴리는 참고집입니다. 사용자의 플레이 단계나 완료 상태를 관리하지 않습니다.

## 1. 수정 전 감사에서 발견한 문제

- `JourneyWorkbench`가 캠페인별 `JourneyDay`를 저장했습니다. 새벽, 날씨, 행동, 길 찾기, 야생, 발견, 조우 해결, 야영 결과가 뒤의 도구를 활성화했습니다. 굴림이 이벤트를 기록하고 날짜를 진행시켰습니다.
- `CampaignProcedures`가 캠페인을 요구하고 여행 진행 화면과 달력을 제공했습니다. Core 재앙에서 SD의 일일 굴림 변형을 추천했습니다.
- `PlayMode`는 세션·조우·개체 상태와 기록을 중심에 두었습니다. 앱 탐색도 PLAY와 Travel 진입 전에 캠페인을 고르도록 유도했습니다.
- `CityCrawlWorkspace`는 `blocked/scene/ready/complete`와 거리 번호를 저장하고 장애물·장면 해결 후 다음 거리로 넘어갔습니다.
- `DungeonCrawlWorkspace`는 `dungeon.crawl`의 단계와 방 발견을 저장하고 위험 및 방 내용을 해결해야 탐색을 진행했습니다.
- 기존 검색, registry, inspector, 원본 표, 굴림, 복사, 출처, 관련 참조는 독립적으로 사용할 수 있어 재사용했습니다.

## 2. 제거·변경한 state architecture

여행의 단계 모델, 준비·완료 selector, 저장 및 날짜 진행 경로를 제거했습니다. 도로 판정·활동·야영 등 독립 계산 함수는 유지했습니다. 도시의 시작·진행·해결·종료 상태 및 `cityCrawlStore`를 제거하고 독립 Move 계산과 표 조회를 유지했습니다. 던전의 시작·방 진입·위험 해결·다음 단계 진행 함수와 화면 연결도 제거했습니다.

기존 여행·도시·던전·PLAY 컴포넌트는 자유 참고 작업대를 여는 호환 진입점입니다. 새 굴림 결과는 메모리에만 남으며 캠페인의 날짜·위치·날씨·조우·HP를 자동으로 변경하지 않습니다. Mythic 입력과 새 판정도 임시 상태입니다.

저장 자료의 읽기·내보내기·복제 호환성에 필요한 역사적 필드는 유지합니다. 새 참고집은 이 필드를 진행 상태로 읽거나 갱신하지 않습니다.

## 3. Workbench의 새 interaction model

검색과 고정·최근 참조 아래에 작업대, 여행·재앙, 던전·방, 도시, 판정·전투 주제를 제공합니다. 각 주제는 registry의 실제 참조를 모아 보여주며 시작이나 완료가 없습니다.

각 카드에서 출처와 공식을 확인하고 **표·공식 보기** 또는 **굴리기**를 선택합니다. Procedure의 구성 표는 처음부터 표시하며 각각 따로 열거나 굴릴 수 있습니다. 정보의 접기는 도구 사용 조건을 만들지 않습니다.

최신 UI 요청도 반영했습니다. 일반 주사위의 면 선택 드롭다운을 d2·d4·d6·d8·d10·d12·d20·d100의 단순한 SVG 도형 버튼으로 교체했습니다. 선택한 도형을 노란색으로 표시하며 키보드와 스크린 리더로도 선택할 수 있습니다. 개수·보정 입력칸과 굴리기 버튼은 동일한 높이로 정렬했습니다. 좁은 영역에서는 도형을 네 개씩 두 줄로 배치합니다.

사용자가 이어서 제공한 주사위 예시의 가운데 줄을 기준으로 면 경계를 다시 그렸습니다. d8의 삼각형 면, d10의 연꼴 면, d12의 오각형 면, d20의 서로 교차하지 않는 삼각형 면을 구분하고 외곽선을 내부 선보다 조금 굵게 표현했습니다.

## 4. Travel 및 situational oracle

날씨, 도로 종류, 도로 사건, 길 이탈, 야영, 조우, 재앙과 여행 규칙을 직접 펼칠 수 있습니다. 원본 절차의 순서는 읽을 수 있지만 선행 굴림이나 완료 조건은 없습니다.

제공된 자료에서 Animal Tracks와 Broken Road는 독립 결과표 이름이 아니라 도로 종류와 길 이탈 판정에 연결된 상황입니다. 별도의 결과를 창작하지 않았습니다. **Animal Tracks / Tracks / Broken Road / 동물 흔적 / 망가진 도로** 검색으로 해당 규칙에 접근하고 `1d20 + Presence / Omens ≥ DR10`을 즉시 굴릴 수 있습니다. 도로·날씨를 먼저 굴릴 필요가 없습니다.

## 5. Disaster source audit

사용자 제공 **MÖRK BORG BARE BONES EDITION** Core PDF pp.17–20과 현재 `core.miseries`를 대조했습니다.

- d66 **1:1–6:6의 36개 항목** 모두 원문과 일치했습니다. 공백 및 문장부호를 정규화한 텍스트 비교입니다.
- 일곱 번째 재앙 **7:7**은 별도 고정 항목이며 원문과 일치합니다. d66 무작위 결과에 섞지 않고 표의 마지막에 구분하여 표시합니다.
- 종말 주사위 d100/d20/d10/d6/d2 및 중복 시 재굴림·일곱 번째 고정 결과 안내를 유지합니다. 이미 발생한 재앙 횟수를 앱이 추적하지 않습니다.
- 현재 제공 자료 묶음에서 Core 이외의 별도 재앙 결과표는 발견되지 않았습니다. Core 관련 참조에서 SD 일일 굴림 변형 추천을 제거했습니다. SD 규칙 자체는 출처가 구분된 참고 자료로 검색할 수 있습니다.
- `core.miseries` 굴림에 Core 출처, d66 및 36개 슬롯 검사를 추가했습니다. 불확실한 재앙 결과를 추정하여 추가하지 않았습니다.

텍스트를 재수록하지 않은 대조 결과: `outputs/freeform-reference/core-misery-audit.json`.

## 6. 유지한 기존 기능

Reference registry, 검색 별칭, 검색 결과, 원본 표 inspector, 독립 굴림, 공식, 출처와 원문 연결, 관련 참조, COPY, 고정 및 최근 참조를 유지했습니다. 캠페인 노트, 세션, 연대기, 보관과 명시적 기록은 선택적 기능으로 남습니다. 기록은 참고집 사용 조건이 아닙니다.

## 7. Migration / compatibility

기존 Campaign save의 스키마 버전과 가져오기·내보내기 경로를 유지했습니다. 이전 `dungeon.crawl` 및 Mythic 이력은 데이터 보존과 왕복 저장을 위해 남지만 새 굴림에서 사용하지 않습니다.

이전 여행·도시 진행 localStorage 키는 삭제하거나 덮어쓰지 않고 새 UI에서는 읽거나 복원하지 않습니다. 기존 replay 자료는 보존하며 새 결과는 영구 저장하지 않습니다. 고정·최근 참조와 사용자가 만든 스크랩은 참고 편의 기능으로 유지합니다.

브라우저에서 기존 캠페인, 해결되지 않은 던전 위험 단계 및 구형 저장 키를 넣어 검증했습니다. 참고 도구 사용과 새로고침 후 캠페인 내용과 구형 저장 값이 그대로임을 확인했습니다.
