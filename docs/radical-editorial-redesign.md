# Radical Editorial Redesign — 검증 기록

2026-09-14 · 기준 커밋 `2a4d88a` · 기본 화면 3440 × 1440.

이번 변경은 표시 계층에 한정한다. Reference ID, source mapping, rules, roll engine, 검색·저장·migration 로직을 변경하지 않았다. 마지막 요청에 따라 한글 제목은 Song Myung, 본문은 Hahmlet으로 적용했다. 손글씨체와 눈 모양 장식은 제거했다.

## 변경 전 화면에서 확인한 문제

1. **홈의 세 영역이 서로 다른 높이에서 시작했다.** 생성기 목록에 별도 상단 여백이 있어 같은 행처럼 보이는 링크의 기준선이 어긋났다.
2. **3440 화면에서 정보가 화면 위쪽에 작게 몰렸다.** 작은 탐색·본문과 넓은 공백 사이에 읽기 규모의 기준이 없었다.
3. **표지 제목·빠른 참조·생성기가 독립 패널처럼 보였다.** 공통된 인쇄면의 행과 열이 없고 얇은 구분선의 중요도가 평평했다.
4. **참조 제목과 결과의 위계가 약했다.** 굴림 값, 항목 이름, 설명이 비슷한 크기의 텍스트로 나열됐다.
5. **넓은 화면에서 한 줄이 길어졌다.** 참조 폭을 늘리는 것과 본문 가독 폭을 구분할 필요가 있었다.
6. **작업대의 작은 제목·본문과 자체 경계가 경쟁했다.** 현재 참조를 읽는 폭과 옆 페이지의 최소 가독 폭을 함께 고려해야 했다.
7. **생성기 설명 길이에 따라 제목 높이가 달라질 수 있었다.** 같은 줄 항목은 내용 길이와 무관하게 위에서 정렬하도록 수정했다.

## 제거·축소한 요소 / 유지한 요소

생성기 목록의 별도 상단 오프셋, 작은 제목 중심 구성, 장식용 눈 그림, 손글씨 서체를 제거·대체했다. 참조 결과의 기존 열린 section 구조를 유지하며 더 큰 서체와 정렬된 규칙선으로 재구성했다. 선택 기록 화면의 카드 배경과 그림자도 평평한 표시로 정리했다. 불필요한 1000개 자동 색인은 복원하지 않았다. 새로운 게임 모드·추천·진행 시스템은 없다.

Home / Reference / Generators, Search, type/source/context 필터, Pins, Recent, Workbench, source disclosure, copy, manual lookup, 명시적인 Roll, 기존 선택 기록 화면을 유지했다. 검색과 필터가 필요한 목록을 열고 제목 선택이 바로 참조를 연다는 관계도 같다.

CSS와 DOM이 전체적으로 줄었다고 주장하지 않는다. 반응형 출판 구도를 위해 CSS가 늘었고, 참조 본문에 wrapper 하나를 추가했다. `ReferenceWorkbench.tsx`의 큰 diff 대부분은 wrapper 내부 들여쓰기다.

## 시각 수용 판단과 남은 한계

A–I는 객관적인 자동 점수가 아니라 실제 Before/After 비교에 따른 디자인 판단이다. 큰 가로 표지, 서로 다른 크기의 서체, 노랑/시안 색면, 검정 규칙선, 비대칭 읽기 면으로 기존 화면과 구성이 분명히 달라졌다. 3m 실제 관찰 실험은 하지 않았다. J의 도구 사용성은 위 UI 점검으로 확인했다.

- 가장 많이 달라진 화면은 홈과 넓은 Reaction이다. 홈은 작은 목록과 빈 화면 대신 큰 인쇄면을 사용하고, Reaction은 표와 결과를 함께 읽는다.
- 제거 효과가 큰 것은 어긋난 목록 오프셋과 작은 글자 위주의 기존 비례다. 강한 요소는 현재 참조 제목, 결과 값/내용, 원본 표의 선택 행이다.
- 색과 서체를 제거해도 공유된 행·열, 순서, 숫자 열, 구획선이 남는다. 로고 없이도 큰 표지와 표 중심의 읽기 구도가 남는다고 판단한다.
- 홈의 큰 글자를 우선해 3440×1440에서도 여섯 번째 빠른 참조는 아래로 일부 이어진다. 모든 링크를 한 화면에 억지로 압축하지 않았다.
- 360에서는 검색·탭 높이가 약 228px이고 참조 제목이 약 300px에서 시작한다. 종류 필터는 가로 스크롤이다. 긴 표는 원본 내용 때문에 길어진다.
- 1440 작업대는 현재 참조 아래에 있어 모든 페이지를 동시에 볼 수 없다. 3440에서도 긴 생물 본문·표는 페이지별 스크롤이 필요하다.
- 기존 선택 기록 화면은 별도 탐색 구조를 유지한다. 폭과 서체를 맞췄지만 기능 구조까지 다시 작성하지 않았다.
- 폰트가 지원하지 않는 희귀 한글·한자는 fallback으로 모양이 다를 수 있다. 출처 원문·번역의 기존 한계는 새로 추측해서 보완하지 않았다.
