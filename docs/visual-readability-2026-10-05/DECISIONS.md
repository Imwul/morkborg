# 생성기·Mythic 가독성 개선 결정

날짜: 2026-10-05

기준: `7fb8050` 이후 현재 앱

방법: BMAD Design Thinking + Party Mode(session), 기존 사용 맥락 → 문제 정의 → 대안 토의 → 구현 → 화면 점검.

사용자가 다섯 제안 모두의 구현을 승인했고, 추가 확인 없이 토의를 동반해 진행하도록 요청했다. 이번 작업은 새 기능을 늘리기보다 완성된 결과를 읽고 종이에 옮기는 흐름을 정리한다.

## 유지할 기준

- PC에서 책과 종이를 곁에 두고 솔로 플레이한다.
- 영어를 먼저 읽고 한글을 보조로 읽는다.
- MÖRK BORG의 큰 이름·강한 색면, 기존 Space Mono 숫자 글꼴을 유지한다.
- 오른쪽 아래 도구는 본문 조작을 막지 않는다. 접기 기능을 추가하지 않는다.
- 후속 요청에 따라 Mythic의 Yes는 기존 검정 잉크색을 쓴다. Yes/No·예외 결과별 녹색/적갈색을 없애고 같은 잉크색으로 통일했다. 새로운 강조색은 추가하지 않는다.

## 대안과 결정

| 항목 | 토의한 대안 | 선택과 이유 |
|---|---|---|
| 1. 캐릭터 결과 | 모든 칸을 균일하게 작게 만들기 / 인물의 이름은 크게 두고 장비와 배경을 묶기 | 후자. 이름·직업 → 수치 → Equipment → Class & powers → Traits & background 순서. 긴 방어구 조건은 수치 줄에서 꺼내 Equipment에 온전히 표시한다. 빈 묶음은 만들지 않는다. |
| 2. 보조 굴림 | 모든 주사위 숫자 축소 / 복합 생성기의 생성 과정만 조용하게 표시 | 후자. 여러 항목의 굴림과 기존 복합 굴림은 열어 볼 수 있는 ‘굴림 내역’으로 두고 결과 뒤에 배치한다. 몬스터 공식에 잘못 적용되던 노란 띠는 생성기에 한해 제외한다. 단일 오라클의 큰 숫자·색면은 유지한다. |
| 3. 참조 링크 | 용어마다 상자·아이콘 붙이기 / 기존 본문에 가는 밑줄 | 후자. 마우스를 올리기 전에도 클릭 가능한 용어를 식별한다. 기존 키보드 포커스 표시는 유지하고 hover에서 밑줄만 강조한다. |
| 4. Mythic 높이 | 폭을 더 좁히기 / 상단 중복 문구와 CF 배치 정리 | 후자. Ask Fate와 Chaos Factor를 같은 줄에 놓고 반복 판본·안내는 접근성 설명에 남긴다. CF 버튼의 조작 면적과 입력·판정·이력 기능은 유지한다. |
| 5. 생성기 복귀 | 생성기 전용 결과 화면 복제 / 기존 참조 화면에 작은 복귀 동선 추가 | 후자. 목록에서 연 항목에는 ‘생성기 목록으로’를 표시한다. 돌아갈 때 기존 생성 결과를 삭제하거나 다시 굴리지 않는다. |

## 토의에서 남긴 쟁점

**Maya:** 필사할 값이 가까이 있어야 한다. 특히 물통·식량처럼 짧은 장비 결과마다 큰 높이를 차지할 이유가 없다.

**Caravaggio:** 전부 작은 관리 화면처럼 만들면 인물이 사라진다. 이름의 크기와 단일 오라클의 극적인 숫자 표현은 남겨야 한다.

**Dr. Quinn:** 공간을 줄여도 조건·번역·굴림 근거가 사라져서는 안 된다. 보기만 재배치하고 저장·복사하는 데이터는 그대로 둬야 한다.

실제 화면에서 첫 배치가 여전히 수치를 아래로 밀어내는 것을 확인했다. 이름 굴림 내역을 이름 레이블 옆으로 옮기고, 캐릭터 설정·동작 줄의 여백을 추가로 줄였다. 1280×720에서 이름과 핵심 수치를 함께 볼 수 있다. 긴 직업명·내용은 필요할 때 줄바꿈하므로 모든 결과의 높이가 같지는 않다.

## 구현 경계

새 묶음은 기존 결과 블록을 참조하는 표시 구조다. 저장 결과·복사 텍스트·원문·굴림 엔진은 변경하지 않는다. 알 수 없는 과거 블록도 버리지 않고 특징·배경 묶음에 남긴다. 방어구의 영문·한글 조건을 자르거나 피해 수치만 추출하지 않는다.

홈의 빠른 참조, 공간 탐색, 기본 참조 화면 구성은 유지한다. 복귀 링크는 현재 브라우징 세션에서 생성기 목록으로 연 항목을 위한 보조 동선이며, 영구적인 출처 표시가 아니다.

## 검증 기록

- 관련 테스트 51개 통과: 결과 묶음의 정보 보존·기존 복사 결과, 캐릭터 생성, 장비·두루마리, 원문 선택 표시, Mythic 규칙, 탐색 이력.
- 클라이언트·서버 TypeScript와 lint 통과.
- 프로덕션 빌드 및 공개 빌드/비공개 데이터 경계 검사 통과.
- Git에 올릴 변경 파일 10개에 비공개 원문이 없고, 비공개 경로 7개가 제외됨을 확인했다. 저장소 전체의 기존 원문 문서 대조는 파일 읽기 지연으로 중단했으며, 전체 저장소 검사가 완료됐다고 보지는 않는다.
- 브라우저: Classless 및 직업 선택 결과, 완전한 직업 규칙·두루마리 설명, 목록 복귀 뒤 동일 캐릭터 유지.
- 브라우저: 몬스터 공식의 투명 배경과 24px 내외 높이, 접힌 굴림 내역을 열어 원문 확인.
- 브라우저: Miseries의 128px Space Mono 숫자·노란 결과 면 유지, 본문 참조의 기본 밑줄 확인.
- 브라우저: Mythic CF 변경·Fate 굴림·장면·인물/스레드 탭, 패널을 연 상태의 본문 페이지 이동.
- 1280×720 및 390×844 확인. 좁은 화면에서 결과는 한 열로 바뀌고 가로 넘침이 없다. Mythic은 화면 높이에 맞춰 내부 스크롤한다.

이는 개발자 화면 점검이며, 사용자의 후속 사용성 평가가 이루어졌다는 뜻은 아니다.

화면 기록은 로컬 `outputs/design-review-2026-10-05/`에 보관한다. 룰북 내용이 나타나는 화면 이미지는 Git에 넣지 않는다.
