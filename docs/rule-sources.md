# 룰북 적용 범위

사용자가 제공한 PDF를 확인하여 만든 개인용 자료와 생성 절차입니다. 화면의 출처는 PDF 뷰어의 1부터 시작하는 페이지 번호이며 인쇄된 쪽수와 다를 수 있습니다. 책에 명시되지 않은 생성표나 규칙은 창작하지 않습니다.

| 자료                                  | 현재 사용 범위                                                                           |
| ------------------------------------- | ---------------------------------------------------------------------------------------- |
| MÖRK BORG BARE BONES EDITION          | 이름, Classless 능력치·HP·장비·은화·징조, 특성, 던전·방·함정·보물, 고정 개체             |
| MÖRK BORG CULT: FERETORY              | The Monster Approaches의 A/B/C 외형, 연결된 HP·사기·방어구·피해, 욕망·특성; 추가 표 열람 |
| MÖRK BORG CULT: HERETIC               | 책에 실린 몬스터와 NPC의 고정 능력치·특수능력; 컬트·묘지·저주 등의 표 열람               |
| Sölitary Defilement                   | 방 이름 구성, 기본 조우, NPC 직업·성향; 추가 표 열람                                     |
| Sölitary Depths                       | 지역별 특성·조우·NPC 직업·발견; 희귀 조우에 허용된 Monster Approaches 대안               |
| RECLVSE — A Solo Engine for Mörk Borg | 던전 입구·상태·용도, 방 내용, NPC와 조우 구성, 2d20 판정과 d100 질문 판정; 추가 표 열람  |

현재 개인 자료에는 193개 표가 있습니다. 모든 표를 생성기에서 실행하는 것은 아니며, 원문 목록 열람은 중첩 주사위·카드·조건부 규칙 전체를 자동 처리하지 않습니다. 선택 직업과 그 보정은 직접 적용합니다.

## 판정 기준과 조합

- Classless는 3d6 능력치 변환, 최소 1 HP인 Toughness+d8, 2d6×10 은화, 선택 규칙 d2 Omens를 사용합니다. 시작 장비의 두루마리가 있으면 무기 d6/방어구 d2 제한을 적용합니다. 한 필드만 재굴릴 때에는 다른 장비·능력치를 자동 변경하지 않습니다.
- FERETORY는 같은 A/B/C 세 결과로 사기·피해·방어구를 정합니다. HP는 본문의 ‘피해 주사위 한 번 ×2’를 따르며, 괄호의 2dN 예시와 다른 분포임을 표시합니다. 최고 주사위가 동률일 때 방어구 선택법은 원문에 명시되지 않아 심판 선택으로 남깁니다.
- 기본 원문 이름 표를 몬스터의 편집 가능한 이름에도 사용합니다. 이름 부여와 여러 책의 결과 조합은 이 기록장의 작업 방식이며, 책의 단일 생성 절차로 주장하지 않습니다.
- 던전의 독특한 특징은 기본 표와 Depths 지역 특성 표를 조합합니다. 공통 표는 유지하고 임의의 지역 확률 가중치를 만들지 않습니다. 방, 일반 조우, NPC 직업에도 해당 지역 원문 표를 사용합니다. Galgenbeck은 상위 지역 Tveland 표를 사용하고, 독립된 원문 표가 없는 Grift는 공통 표로 돌아갑니다.
- 고정 개체에는 원문 능력치를 사용합니다. Zukuma의 무기 표, The Übertaker의 라운드 행동 표, NPC의 특수능력도 보존합니다. 개체 HP가 수치로 제시되지 않은 특수한 항목은 프리셋 목록에서 제외합니다.
- 일반 NPC의 원문 조합에 HP·방어구 등 수치가 없으면 공란입니다. 몬스터의 별도 약점·전리품처럼 대응 표가 없는 항목도 수동 작성용으로 남깁니다.
- RECLVSE의 2d20은 기본 DR12와 선택 DR10, 첫 번째 치명 판정 주사위를 적용합니다. 질문 판정은 PDF85의 표에 있는 ‘이하’를 적용하며 같은 페이지 설명의 ‘미만’ 표기와 다름을 표시합니다.

원문에 있는 선택지(`/`), 주사위 표현, 미해결 조건은 의미를 임의로 축약하지 않고 남깁니다. 각 결과에는 출처가 저장되고, 사용자가 편집하면 직접 작성임을 표시합니다. 부분 재굴림은 대상 필드만 바꾸므로 연결된 수치를 조정하려면 전체 재굴림 또는 직접 편집을 사용하세요.

## 공개 생성기 대조

2026-09-02에 DNGNGEN과 The Monster Approaches의 공개 JavaScript·소스맵, DNGNSTOCK의 공개 Perchance 모델을 살펴보았습니다. DNGNGEN의 제목·개요와 방 네 개를 먼저 보여 주는 흐름을 후보 화면에 반영했습니다. DNGNSTOCK의 방 내용 구성과 출처도 대조했습니다. 생성 문구는 이 환경에 제공된 책의 실제 표를 사용하며, 웹사이트의 전체 텍스트 모음을 공개 저장소에 옮기지는 않습니다.

The Monster Approaches 웹 구현의 일부 방어구 분기는 FERETORY와 달라, 이 앱은 책의 C 최고 주사위일 때 홀수 −d4 / 짝수 −d6 규칙을 유지합니다. 책의 표 제목이 결과에 섞이는 추출 오류도 확인하여, Occult treasures를 실제 결과 열 개로 바로잡고 잘못된 자료를 불러오지 못하도록 검사합니다.

## 개인 자료와 공개 코드

제공된 책의 표는 `public/rules/library.json`에 개인 자료로만 보관합니다. Git에는 포함되지 않습니다. 원본 PDF, 추출 중간 파일, 사용자 캠페인은 코드 저장소에 추가하지 않습니다. 이 저장소의 공개는 책의 내용에 대한 재배포 허락을 의미하지 않습니다.
