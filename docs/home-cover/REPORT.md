# Home cover refinement

## 변경

홈을 큰 산성 노랑 표지, 검정 검색 띠, 굵은 목차로 바꿨다. 홈 로고는 모바일에서 두 줄, 넓은 화면에서 한 줄로 나타난다. REFERENCE는 검정 바탕과 노랑 제목으로 주요 진입점이 되고, PLAY만 마젠타 구분선을 사용한다. CODEX와 보조 관리는 종이 바탕에 남긴다.

- 제목 크기: 360 px에서 **24 → 70 px**, 1440/3440 px에서 **36 → 158 px**.
- 768 px에서는 제목 82 px, Reference/Play 두 열, Codex 전체 너비.
- 3440 px에서는 홈을 1280 px로 제한한다.
- 기존 전체 목차 버튼 **23개 그대로**. 보조 기록은 닫힌 상태를 유지한다.
- 새 글꼴, 이미지, 장식 문양, 도메인, 룰/테이블/생성 데이터 추가 없음.
- 홈 CSS 소유 파일을 직접 수정했다. 전역 스킨이나 결과/규칙 읽기 스타일을 덮지 않았다.
- 검색을 표지 바로 아래에 붙였다. 큰 제목의 시각적 공간은 의도적으로 늘렸으며 페이지가 더 짧아졌다고 주장하지 않는다.

## 실제 화면 검토

`outputs/home-cover/`의 로컬 전후 화면과 검색 화면을 확인했다. 360/768/1440/3440 px, light/dark 각각을 브라우저에서 검사했다. 처음 사용하는 빈 상태도 360/1440 px에서 확인했다.

- 첫 시선은 홈 제목과 검색으로 간다. 관리 링크들이 같은 크기의 카드로 경쟁하지 않는다.
- 모바일 로고는 넘치지 않고 두 줄로 접힌다. 한글 메뉴가 읽히며 버튼 높이는 모두 44 px 이상이다.
- 노랑/검정, 종이/검정, 마젠타/검정의 글자 대비는 각각 **15.85:1 / 18.05:1 / 5.84:1**. 검색 placeholder 대비는 **13.16:1**.
- 두 시스템 색상 설정에서 기존 종이/잉크 팔레트를 유지한다. 새로운 테마 전환 기능을 만든 것이 아니다.
- 가로 넘침, 제목 잘림, JavaScript 오류 없음. 검정 Reference 영역에서도 키보드 포커스가 보인다.
- 기존 고정 하단 도구가 스크롤 내용 일부를 덮는 구조는 그대로다. 이 변경은 해당 도구나 일반 결과 화면까지 다시 디자인하지 않는다.

## 동작 및 데이터

`verify.mjs`는 각각의 크기/색상 조합에서 검색 → Reaction 직접 굴림 → 복사 → 출처 → 닫기 → 새로고침을 실행한다.

| 동작 | 전 | 후 |
| --- | --- | --- |
| 검색 결과에서 바로 굴림 | 1 | 1 |
| 결과 복사 | 1 | 1 |
| 출처 열기 | 1 | 1 |
| 홈에서 기존 영역 열기 | 1 | 1 |

검색/굴림/복귀/새로고침 후 Campaign 저장 문자열이 동일함을 확인했다. `home-bilingual/acceptance.mjs`도 재사용해 기존 전체 목적지, Dungeon/Room 한국어 병기, 수동 편집의 출처/번역 경계를 검증한다. 검사는 격리 브라우저의 QA 저장 데이터에서만 실행한다.
