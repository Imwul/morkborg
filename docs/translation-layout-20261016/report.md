# 한국어 번역·캐릭터 시트 개선

2026-10-16 · 시작 커밋 `1af74e321a7f10bef434ffd181e85bdc1ece362f`

## 적용한 개선

- 공통 번역 표시에서 `근력는`, `민첩와`, `지각는`, `권능를`처럼 영어를 한국어로 치환한 뒤 남던 잘못된 조사를 교정했다. 기존 자료에서 확인된 31곳이며 같은 표시 경로에 적용된다.
- 원문의 능력치가 확인되는 경우에 한해 체력(Toughness)·지각(Presence)·민첩(Agility)으로 용어를 통일했다. 사전의 73문구에 적용되는 교정이다. 일반적인 건강 묘사, 소문자 presence의 존재감, 사용자가 직접 쓴 저장 내용은 일괄 치환하지 않았다.
- 건강/강인함이 섞이던 캐릭터 요약·수치 제목을 체력으로 맞췄다. 오멘 상세 제목의 ‘징조’와 치명타·실수 안내도 정리했다.
- 생성 방식·직업 선택·능력치 선택 규칙·오멘 설정, 오라클 가능성·날씨·사냥 설정, 일반 판정·전투·조건별 판정 입력에 한글을 보완했다. 선택값과 상태 키는 유지했다.
- 단수 Power/Omen과 동적으로 생성되는 `Power uses/day` 제목을 번역했다. 화면과 새 보관 스냅샷에 같은 원문 문맥을 전달한다.
- Sölitary Depths의 Fetid Gas에서 정확한 `TR Omens Move` 문맥의 ‘TR 전조 행동’을 ‘TR 오멘 행동’으로 바로잡았다. 일반 서술의 ‘전조’는 유지했다.
- 활성 캐릭터 시트의 능력치 라벨을 영문·한글 두 줄로 정리하고 긴 한글은 단어 단위로 줄바꿈하되 긴 문자열은 화면 안에서 다시 감싸도록 했다. 새 안내 다음 장비 구역의 간격을 보정했다.

원문 영어, 표의 행·주사위·확률·판정 엔진·저장 형식은 변경하지 않았다. 기존 보관 텍스트를 소급해서 다시 번역하거나 덮어쓰지 않는다.

## 작은 사용 횟수 안내와 원문 근거

**오멘:** Core 선택 규칙. 모두 소진한 뒤 최소 6시간 쉬어 직업 지정 주사위만큼 회복한다. 직업 없음은 d2다. 캐릭터 결과에 Omens가 있을 때만 수치 아래 표시한다. 남은 오멘을 아침마다 다시 굴린다고 안내하지 않는다.

**권능:** 매일 아침 지각+d4로 그날 사용 횟수를 정한다. 두루마리 판정에 성공하면 1회 소모한다. `Power uses/day` 결과 바로 아래 표시하며 직업 능력의 별도 횟수는 해당 설명을 따르도록 명시했다. 모든 SCVMBIRTHER 직업 특성에 같은 횟수를 적용하거나 최소 1회를 보장하지 않는다.

Core BARE BONES EDITION PDF34·37쪽을 원문으로 다시 확인했다. 실패 시 발동 없음·HP d2 손실·1시간 어지러움 등 전체 조건은 기존 권능 상세에 유지한다. FERETORY의 Pale One PDF60/인쇄58쪽은 하루 권능 **1종**이며 1회로 바꾸지 않는다. Forlorn Philosopher PDF64/인쇄62쪽의 문신·Prism 횟수와 Sash의 착용 일수는 별개다. 새 안내는 각각 기존 Core 규칙으로 연결한다. Fetid Gas는 Sölitary Depths PDF13/인쇄10쪽과 대조했다.
