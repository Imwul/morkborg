# 라이트 / 다크 시스템 설정의 글자 대비 점검

2026-09-09. 시각 정리 커밋 `230610fa4e74839aa26665bbed7767c71d999aca`에 대한 후속 확인이다. 사용자의 “라이트모드 다크모드에서 글자가 안 보이지는 않나” 요청에 따라 실제 브라우저의 시스템 색상 선호를 바꿔 점검했다.

앱 자체에는 테마 전환이 없다. `color-scheme: light`와 고정된 종이색/검정 팔레트를 사용한다. 따라서 OS 다크 설정에서도 본문을 검게 바꾸는 새 테마를 만들지 않았다. 밝은 본문, 검은 정체성 영역, 노란 강조 영역과 실제 입력·호버·포커스 상태에서 글자가 읽히는지를 확인했다.

## 발견과 수정

| 실제 문제 | 수정 | 측정 대비 · 이전 → 이후 |
|---|---|---|
| 몬스터 이름을 편집하면 검은 textarea 글자가 검은 정체성 배경에 묻힘 | 편집 중인 필드에 종이색 배경, 라벨에 기존 진한 보조색 적용 | **1.00:1 → 18.05:1**; 포커스 입력면 19.69:1 |
| 던전 지역 설명이 흐림 | 기존 `--muted-ink` 사용 | 3.64:1 → 5.78:1 |
| 비활성 던전 탭 이름이 흐림 | 기존 `--muted-ink` 사용 | 3.98:1 → 5.78:1 |
| 탭 개수의 별도 연녹색 글씨가 흐림 | 탭의 텍스트 색 상속; 선택된 탭은 검정 유지 | 3.62:1 → 비선택 5.78:1 |
| 아직 방을 선택하지 않은 노란 안내 영역의 회색 설명이 흐림 | 안내·작은 라벨·아이콘을 기존 진한 보조색으로 통일 | 문구 3.12:1 → 5.08:1 |
| 흰 글씨 버튼의 `currentColor` 포커스 외곽선이 종이 배경에서 사라짐 | 검은 외곽선 + 종이색 안쪽 링 | 밝은/어두운 면 모두에서 실제 포커스 표시 확인 |

일반 표시와 편집 상태의 색 소유권만 수정했다. 새 전역 테마, 데이터, 규칙, 번역, 생성 확률, 저장 형식, 검색 관계를 바꾸지 않았다. 흐린 글씨를 없애기 위해 기존 노란 강조나 캐릭터의 마젠타 정체성을 제거하지 않았다.

## 검증 범위

- **21개 화면/상태 × 360 / 1440 / 3440px × OS light / dark = 126개 캡처.** Desk, Search, Oracle, Source, Table, RECLVSE, Depths cards, Character 읽기/편집, Dungeon, Room 읽기/번역/편집, Monster 읽기/편집/이름 입력, NPC, Encounter, Encounter Level, City, Power를 포함한다.
- 열린 화면의 본문·라벨·실제 입력값·placeholder·선택값을 검사했다. 접힌 내용과 의도적으로 투명한 제어는 제외했다. 비활성 제어는 별도로 분류했다. 여러 화면에 반복된 글씨를 합쳐 **7,872회 관찰**, 활성 글씨의 대비 미달 **0**, 측정 최저 **5.26:1**. 이를 고유 항목 수나 테스트 수로 부풀리지 않는다.
- 별도 **24개 호버/키보드 포커스 검사**: REROLL, COPY, SOURCE, 검은 Character 헤더의 Class 링크, 검은 Monster 헤더의 이름, 이름 편집 입력. 최저 **4.62:1**, 포커스 상태 확인.
- 방 미선택 안내문은 두 시스템 설정과 세 폭에서 **6회 추가 확인**, 모두 **5.08:1**. 첫 방의 이동 불가 제어는 두 설정 모두 표시되면서 disabled를 유지한다.
- 모든 캡처 폭에서 가로 넘침 0, 브라우저 오류 0. 실제 캠페인 내용 비교도 통과했다. QA는 별도 브라우저 컨텍스트만 사용했으며 사용자의 저장 데이터를 수정하지 않았다.
- 대표 화면을 이미지로 읽었다. 특히 라이트/다크의 Monster 이름 입력, 검은 Character 헤더 포커스, Oracle 포커스, 360px 이름 입력과 빈 방 안내를 직접 비교했다. 126장 전부를 사람이 한 장씩 검토했다고 주장하지 않는다.

| OS 선호 | 폭 | 캡처 | 글씨 관찰 | 활성 대비 미달 | 가로 넘침 |
|---|---:|---:|---:|---:|---:|
| light | 360 | 21 | 1,052 | 0 | 0 |
| light | 1440 | 21 | 1,442 | 0 | 0 |
| light | 3440 | 21 | 1,442 | 0 | 0 |
| dark | 360 | 21 | 1,052 | 0 | 0 |
| dark | 1440 | 21 | 1,442 | 0 | 0 |
| dark | 3440 | 21 | 1,442 | 0 | 0 |

OS 다크 선호에서도 native `color-scheme`은 light로 유지됐다. 스크린샷 바이트의 동일 여부를 테마 가독성의 기준으로 삼지 않았다. 대비 수치는 계산된 전경/배경색을 합성한 추정이며, 이미지와 상호작용 검토를 보완한다. 모든 브라우저·강제 고대비 모드에 대한 접근성 인증은 아니다.
