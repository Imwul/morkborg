# Journey 카드 글자 대비 수정

사용자가 보낸 모바일 사진의 검정 위 검정 글씨를 실제 공개 앱에서 재현했다. 이전 대비 검사의 City/Encounter Level 화면과 별개로, Campaign의 Journey 단계 카드는 빠져 있었다.

원인은 `.journey-block`의 `var(--card, #12130e)`였다. 현재 팔레트는 `--card`를 정의하지 않아 과거의 어두운 fallback 배경을 사용하고, 글씨는 검은 `--foreground`를 상속했다. 동일한 미정의 card fallback은 다른 CSS에서 발견되지 않았다.

수정은 `src/journey.css`의 카드 배경을 `--background`, 글자색을 `--foreground`로 함께 지정하는 것으로 제한했다. 완료/대기 단계와 펼친 본문은 종이색 바탕에서 읽히고, 현재 단계의 노란 강조는 유지한다. 규칙·원문·한국어·상태 전이·저장·굴림 확률은 바꾸지 않았다.

실제 UI에서 새벽 → 날씨 → 여행 단계로 진행하고, 완료/대기 단계를 펼쳐 본문과 Source를 확인했다. 각 4개 상태를 360 / 1440 / 3440px, OS light / dark에서 캡처했다.

| 검사 | 수정 전 공개 앱 | 수정 후 로컬 production build |
|---|---:|---:|
| 캡처 | 24 | 24 |
| 글씨 대비 미달 관찰 | 519 | 0 |
| 최저 측정 대비 | 1.06:1 | 5.42:1 |
| 가로 넘침 / 브라우저 오류 | 0 / 0 | 0 / 0 |
| 새로고침 후 진행 상태 | 유지 | 유지 |

반복 화면/폭의 관찰 수이며 519개의 고유 결함이라는 뜻이 아니다. 계산된 단색 전경/배경 대비와 대표 스크린샷을 함께 검토했다. 모바일 완료·대기·진행 상태, 모바일 펼친 Source/날씨 결과, 데스크톱 여행 단계를 직접 이미지로 읽었다. 사용자 브라우저 데이터는 사용하지 않았다.

- 기존 658개 테스트 통과, 실패/skip 0. CSS 토큰용 unit test를 추가하지 않았다.
- lint, TypeScript, production build 통과. 공개 빌드 privacy 검사 74개 파일 통과.
- 회귀 도구: `tools/journey-contrast.mjs`. 수정 후 모드에서는 글씨 대비 미달/가로 넘침/진행 상태 손실이 있으면 실패한다.
- 집계: `journey-contrast-summary.json`. 원문을 포함한 이미지/세부 결과는 로컬 `outputs/visual-quieting/journey-{before,after}/`에만 남긴다.
- 푸시 후 공개 URL 검사 결과와 전달 커밋은 완료 메시지에서 별도로 보고한다.
