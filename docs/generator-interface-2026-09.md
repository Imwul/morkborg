# Generator interfaces and inline equipment

The generator index uses the home page's editorial type and separate primary cards. The nine entry points share compact source controls, a result toolbar before the reading, and collapsed source tables. Long result paragraphs use the UI face; existing roll-number typography is unchanged.

Core character equipment now exposes the earlier container choices beside the donkey result. Sacred and unclean scroll slots roll their explicit linked table in place. The selected name and effect replace that equipment value on screen, Copy and saved objects. Child rolls are tied to their parent roll identity, so a new character does not inherit the previous scroll.

The private Monster Approaches source accepts an optional local `private/monster-site/ko.json` companion with format `reference-desk.monster-site-ko`, version `1`, the verified source's `sourceSha256`, and a `messages` mapping keyed by source message ID. This follows the existing private SCVMBIRTHER companion convention. The server reads it on each pack request; malformed or mismatched companions do not replace the verified source.

Monster translations replay the same random draws and preserve ICU variant selections, numeric rules and English results. The title and each result block receive explicit Korean helpers. Source and translation prose remain in the ignored private directory, outside Git and public assets. The active local companion was checked for 446 message keys, 879 rendered template variants and 10,000 generated results.

Validation covers inline scroll Copy/save, parent replacement, rejected unrelated child rolls, translated monster variants, unchanged random-draw counts, checksum isolation and malformed/stale companions. The local template audit also compares dice/DR notation and validates every selected result has a Korean helper.
