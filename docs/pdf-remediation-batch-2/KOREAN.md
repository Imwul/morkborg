# Batch 2 한국어 병기 보완

Batch 2 완료본(`c1fdebba2e81494d22d788a00652442104526472`)에서 새 참조의 한국어 표제는 있었지만 본문 번역과 Reference Desk의 병기 렌더링이 빠져 있었다. 이번 수정은 그 누락을 보완한다.

- 정의 55개: 본문 149개, 소제목 117개, 원문 충돌·오기 설명 14개에 별도 한국어 보조문을 추가했다.
- 영어 바로 아래에 한국어를 표시한다. RECLVSE 규칙/Move, SD 변형과 시작·종료·야외 절차, HERETIC 화약 무기, Mythic 후속 안내, Depths 절차를 포함한다.
- 카드의 외형·특징·의도·특수 능력, 계산된 능력치와 조우 후속 지시에도 병기를 적용했다. 이미 있던 카드 표의 번역을 재사용하며 생성 알고리즘은 변경하지 않았다.
- 변종/참가자와 Rotten Nurse/Mikhael의 정의, 참조 묶음, 다음 참조, TABLE 안의 상세 규칙도 병기한다. 원문에 없는 고유명사 음역이나 새 효과는 만들지 않았다.
- 번역은 `metadata.blocks[].translation`에 영어와 분리해 보관한다. `origin: app`, 번역판 ID, 영어 본문 해시를 함께 기록한다. 데이터는 기존 private bundle 경로로 암호화한다.
- 이전 캐시에는 영어 본문과 제목이 정확히 일치하는 블록에만 번역을 보충한다. 수동 변경한 블록과 기존 사용자 번역은 보존한다. 저장된 Campaign/Character/생성 결과의 재생성이나 스키마 변경은 없다.
- 출처는 계속 접혀 있다. 열면 원문 모순의 한국어 설명도 읽을 수 있다. 한국어 본문은 14px로 표시하며 긴 Move에는 세로 스크롤을 유지한다.

검증: 기존 608개 + 새 8개, **616개 테스트 통과**, lint/build 통과. 전체 원문 항목의 영어·굴림 범위·주사위 해시는 수정 전과 동일하며 출처 미해결 생성 항목은 0이다. 새 테스트는 번역 누락, 주사위/DR 보존, TABLE 표시, 기존 캐시 갱신, 수동 번역 보존을 확인한다.

실제 Chrome에서 55개 정의의 모든 본문을 영어·한국어로 대조했다. 카드 출처 → TABLE → Back 복원, 특수 생물 정의, 출처 예외 설명, reload, 이전 Batch 2 캐시의 API 갱신을 포함해 **63개 검사**가 통과했다. 360/768/1440/3440에서 6개 화면씩 **24개 반응형 검사**를 했으며 가로 넘침과 page error는 없었다. 화면 캡처는 private `outputs/batch-2-korean/`에 보관했다. [브라우저 검사 기록](korean-browser.json)

실제 사용자 브라우저 대신 격리된 QA context를 사용했다. 공개 배포나 push는 수행하지 않았다.
