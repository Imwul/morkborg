# 캐릭터 시트 생성 맥락·RECLVSE 시작 축복

2026-10-16 · 기준 커밋 `d15e60a546a8cd2a4971fcde35a7ee3b1a8bf0a9`

## 변경과 판단

- 능력치 값 아래에 실제 생성 기록으로 확인되는 `3d6−2 → 보정치`, `4d6 · 최저 1개 제외 → 보정치` 등을 작은 글씨로 표시했다. Pale One의 변환 후 보정은 `3d6 → 보정치 +1`로 구별한다. HP·오멘·은화·일일 권능에도 해당 생성식을 표시한다.
- 시트 하단 직업 규칙에서는 상단에 옮긴 능력치 생성 문장만 제거한다. 직업의 서사, 공격·방어 DR, 문맹, 두루마리·방어구 제한과 장비 선택 주사위는 유지한다. 원본 결과와 복사·보관의 원문은 변경하지 않는 표시용 투영이다.
- 장비·능력에 기록된 출처를 사용해 공통 시작 장비, 직업 장비, 직업 능력에서 얻은 장비, 직업의 시작 능력을 구분했다. 원문의 선택지에서 앱이 무작위로 고르는 경우도 명시한다. 서사를 새로 창작하지 않는다.
- 두루마리가 없어도 일일 권능을 소비하는 Pale One·Songbird의 기존 생성 횟수가 시트에서 누락되던 문제를 고쳤다. 횟수를 새로 지급하거나 생성 엔진의 확률을 바꾸지 않았다. 권능 횟수와 사용 안내를 상단으로 함께 옮겼다.
- RECLVSE Starting Blessings 다섯 가지를 기존 캐릭터 생성 화면 안의 접힌 선택 영역에 추가했다. 기본은 선택 없음. 설정 변경은 다음 생성에만 적용되며 현재 캐릭터·과거 보관 내용을 소급 변경하지 않는다. SCVMBIRTHER에는 적용하지 않는다.
- Enhanced Fortitude만 생성 시 HP를 즉시 대체한다(12 고정 또는 10+d4, 체력·직업 HP 주사위 미가산). 다른 네 축복은 퀘스트·관계·사망 등의 조건과 대가를 시트에 보존한다. 조건부 HP·진척·능력치·오멘·장비를 무료로 지급하지 않는다. 별도의 캠페인 기록 기능은 추가하지 않았다.
- 선택된 축복, HP 방식·최종 HP는 복사·보관·Replay에 남는다. 과거 Last/Replay에 새 설정 키가 없을 때 현재 선택한 축복을 물려받을 수 있던 실행 경로를 차단했다. 설정 없는 과거 자료는 축복 없음·고정 HP 방식의 기본값으로 실행한다. 저장 원본 자체는 이 정규화로 덮어쓰지 않는다.
