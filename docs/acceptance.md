# 검증 기록

2026-09-02, 로컬 앱과 Codex 내장 브라우저에서 확인했습니다.

- THE ASHEN PSALM 생성, Classless 캐릭터 Torvul 저장.
- Graven-Tosk의 The Sepulchre of Seven Tongues 생성.
- 입구만 재굴림하여 다른 열 개 필드 유지 확인. 독특한 특징 직접 편집.
- 방 네 개 생성, 방 2를 The Tongueless Choir로 변경.
- 몬스터의 특수능력만 재굴림하여 HP·외형 등 나머지 유지 확인.
- Harmug를 방 2, Agn을 방 미지정 상태로 던전에 배치.
- 희귀 조우 Belum을 방 4, NPC Vagal을 던전에 배치.
- 새로고침 후 캐릭터, 던전 지역, 수동 편집, 방 순서, 배치 참조 유지 확인.
- 여러 화면 전환과 새로고침 후 미저장 몬스터 초안과 메모 유지 확인.
- JSON 내보내기 창의 전체 내용을 보관하고 캠페인 삭제 후 붙여넣기로 복원. 내보내기 JSON이 복원 전후 정확히 일치함을 확인.
- 검색 결과로 방 2에 이동하고 방 순서를 변경한 뒤에도 몬스터 참조 유지 확인.
- 데스크톱과 360×800에서 화면 확인. 모바일 던전·방·몬스터 화면의 문서 가로 넘침 없음. 긴 던전 제목 줄바꿈, 배치 선택창, 사이드바 서랍 확인.
- 파일 다운로드 이벤트는 내장 브라우저 자동화에서 확인되지 않아 JSON 복사/붙여넣기 경로로 왕복 검증함. 파일 선택 가져오기는 별도의 JSON 파일로 성공을 확인함. 일반 브라우저의 파일 다운로드 완료는 별도 확인 대상.

자동 검사는 능력치 경계, 표 가중치, FERETORY 수치 연결, 두루마리 장비 제한, UUID 참조·복제·삭제, 잘못된 가져오기 차단, 미저장 초안, 지역 출처, 프리셋 특수능력, 불완전한 자료 가져오기를 다룹니다. 개인 자료가 있는 환경에서 13개 테스트를 실행했습니다. 자료 파일이 없는 공개 체크아웃에서는 원문 자료가 필요한 테스트가 명시적으로 건너뛰어집니다.

React/Vite 프로덕션 빌드와 TypeScript 검사를 수행했습니다. 별도의 소스 검토에서 7개 지역의 생성 420건과 프리셋 37개를 검증했습니다.
