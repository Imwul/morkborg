React/Vite 프로덕션 빌드와 TypeScript 검사를 수행했습니다. 별도의 소스 검토에서 7개 지역의 생성 420건과 프리셋 37개를 검증했습니다.

## 생성 후보 및 한글 화면 개선

같은 날 추가 확인했습니다.

- 제목을 입력하지 않고 생성기를 열면 개요 11개와 방 네 개를 갖춘 후보가 나타남을 확인했습니다. 반복 재굴림 중에는 저장된 던전 수가 늘어나지 않습니다.
- 입구와 제목을 각각 재굴린 전후의 화면 값을 비교하여, 대상 한 항목만 달라졌음을 확인했습니다.
- 직접 작성 모드의 빈 후보에서 제목과 입구를 쓰고 다른 항목을 굴려도 수동 입력이 유지되었습니다. 방 하나의 위험 / 함정만 굴렸을 때 다른 방과 개요 값은 그대로였습니다.
- 한글 두 줄의 직접 입력과 후보 메모가 다른 화면 이동 및 새로고침 후 그대로 복원되었습니다.
- 선택 전후의 캠페인 내보내기 JSON을 비교했습니다. 저장 시각을 제외한 후보의 내용·출처·UUID·방 네 개의 데이터가 모두 일치했고, 기존 던전은 바뀌지 않았습니다. 검증용으로 저장한 던전은 확인 후 삭제했습니다.
- 3440×1440에서 콘텐츠 영역 약 3145px, 개요 네 열을 확인했습니다. 1920×1080에서 두 열, 360×800에서 한 열이며 문서 가로 넘침이 없습니다. 한글 제목의 Black Han Sans와 본문의 나눔스퀘어 네오, 넓힌 행간을 화면으로 확인했습니다.
- 자료 로드 요청 중복·가져오기 경합과 HMR 복원을 보완했습니다. 자료가 준비되면 기다리던 첫 후보를 만들고, 이미 직접 작성하거나 편집한 후보는 유지합니다.
- PDF 표 제목이 보물 결과에 포함된 추출 오류를 교정했습니다. 실제 결과 열 개 및 올바른 가중치를 검사합니다.

TypeScript·프로덕션 빌드·린트가 통과했습니다. 개인 자료가 있는 작업 환경에서 자동 검사 17개가 모두 통과했으며, 새 검사는 후보 생성·선택·복제·JSON 복원 및 자료 로딩 경합을 다룹니다.
